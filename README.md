2. Описание приложения
**EcoRoute Navigator** — это инновационное мобильное приложение на базе Flutter, предназначенное для построения экологически эффективных маршрутов. Основная идея проекта заключается в минимизации углеродного следа пользователя при передвижении по городу. Приложение не просто прокладывает кратчайший путь, а анализирует экологичность различных видов транспорта: от электросамокатов и велосипедов до общественного транспорта с низким уровнем выбросов.
Приложение решает проблему низкой осведомленности горожан о влиянии их передвижений на окружающую среду. В условиях глобального потепления многие стремятся вести экологичный образ жизни, но не имеют удобного инструмента для оценки и снижения выбросов CO2 в реальном времени. **EcoRoute Navigator** предоставляет прозрачную статистику сэкономленных выбросов и мотивирует выбирать «зеленые» альтернативы.
Целевая аудитория приложения включает экологически ответственных городских жителей, студентов, офисных работников и «цифровых кочевников», которые предпочитают активные способы передвижения. Сервис будет полезен всем, кто хочет внести личный вклад в сохранение экологии города, сохраняя при этом мобильность и комфорт перемещения.
